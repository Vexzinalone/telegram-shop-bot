# ربات فروشگاهی تلگرام

این پروژه یک نمونه ساده از ربات فروشگاهی شبیه تصویر شماست.

## اجرا

1. Python 3.10 یا جدیدتر نصب کنید.
2. وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

3. از BotFather یک Bot Token بگیرید.
4. متغیرهای محیطی را تنظیم کنید:

Linux/macOS:
```bash
export BOT_TOKEN="توکن_ربات"
export ADMIN_ID="آیدی_تلگرام_ادمین"
```

Windows PowerShell:
```powershell
$env:BOT_TOKEN="توکن_ربات"
$env:ADMIN_ID="آیدی_تلگرام_ادمین"
```

5. اجرا:
```bash
python bot.py
```

دیتابیس SQLite به‌صورت خودکار ساخته می‌شود.
